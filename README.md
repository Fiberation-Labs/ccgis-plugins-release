# ccgis-plugins-release

QGIS-Plugin-Repository für die CCGIS-Plugins der Fiberation GmbH. Enthält nur `plugins.xml`, Icons und die installierbaren Plugin-ZIPs. Der Quellcode liegt im privaten Repo `fiberation-ccgis-plugins`.

## In QGIS einrichten

*Erweiterungen > Erweiterungen verwalten und installieren > Einstellungen > Hinzufügen …*

- Name: `Fiberation CCGIS`
- URL: `https://raw.githubusercontent.com/Fiberation-Labs/ccgis-plugins-release/main/plugins.xml`

Danach erscheint **GIS-NB Check** unter *Alle* und Updates werden unter *Aktualisierbar* angeboten.
